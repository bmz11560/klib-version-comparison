## 几个买了才知道的坑

**平台限制是硬的。** App Store 页面标得很清楚，仅适用于 Mac，要求 macOS 10.13 或更高版本。装不了就是装不了，没有绕过去的办法。

**Pro 不含 Amazon 导入。** 前面说过，这里再强调一次，因为这是最容易产生预期落差的地方。你花钱去掉了书籍数量限制，但如果你想直接从 Amazon 抓标注，还得另外订阅 Extensions。

**Extensions 是订阅，会自己续。** 不用的月份记得提前关掉，官方给的时间窗口是周期结束前 1 天。忘了关就是白扣一期。

**免费版的上限是 10 本，不是 10 个标注。** 单本书里划多少条都行，卡的是书的数量。所以“我就一本书里划了两千条”这种用法，免费版完全够。

**它的定位很窄。** Klib 管理的是“标注”这个环节，帮你把散在几个阅读平台里的高亮和笔记收拢到一处，方便回看、检索、导出。它不会让你读得更快，也不会替你做笔记。如果你本来就不怎么划重点，买回去大概率闲置。

**授权和交付方式以商品页为准。** 第三方商店卖软件授权，具体怎么激活、绑定什么账号，商品页会写，下单前花半分钟看一眼，比事后找客服快。

## 常见问题

**Klib 有 Windows 版吗？**
没有。App Store 页面标注仅适用于 Mac。

**免费版能管理多少本书？**
10 本。书籍数量受限，单本书内的标注数量不受限。

**买了 Klib Pro 还需要订阅吗？**
Pro 是一次性解锁无限书籍，本身不含订阅。但如果你想从 Amazon 直接导入标注，需要另外订阅 Klib Extensions。

**Extensions 的 1.99 和 19.99 美元有什么区别？**
App Store 的内购列表里两个价位都有，对应不同的订阅周期，页面上没写清各自的具体时长，购买时看弹窗提示。

**在荔枝商店买和在 App Store 买有什么不一样？**
渠道不同，价格和授权形式可能不同。荔枝这边能用商店的首单券和会员券，App Store 那边没有这些。具体交付方式看商品页说明。

**标注数据存在哪？**
Klib 是本地 Mac 应用，数据在你自己的机器上。它提供整库导出功能，这也是我建议长期用的人直接买 Pro 的原因，数据你拿得走，不存在被锁在某个订阅里。
